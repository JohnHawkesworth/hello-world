# AGENTS.md

## Low-usage working rule (JJ, 13 Nov 2026)
1. Start: read the client's Notion page once and write a short task brief (goal, decisions, open items, links). Open Drive only if needed.
2. Work from that short summary until the task is done. Don't carry long chat history, whole files, full DB dumps or long logs.
3. Coding: one step per fresh run with a short brief (step, files, tests). Read only the functions being changed. Tests print pass/fail and failures only; full sweep once before preview.
4. For the same site, keep changes to shared code, data or decisions sequential; independent work can run alongside. Re-check the relevant Notion notes before merging or deploying, or when a dependency changes.
5. Finish or blocker: send Care one short note (client, done, waiting, Notion link), once per batch.
6. Care alone updates Notion; the next task starts fresh from Notion.
